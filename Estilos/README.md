# Organizacion de estilos EcoPoints

- `main.css`: punto de entrada; importa todos los archivos en orden.
- `00-Base`: colores y reglas generales.
- `01-Navegacion`: barra superior y pie de pagina.
- `02-Componentes`: botones, tarjetas, formularios, tablas y avisos.
- `03-Visitante`: inicio, secciones, busqueda y puntos de acopio.
- `04-Acceso`: inicio de sesion y registro ciudadano.
- `05-Ciudadano`: perfil, indicadores e historial visual.
- `06-Administrador`: panel administrativo.
- `07-Adaptable`: reglas para tabletas y celulares.

Todos los HTML enlazan `Estilos/main.css`; no deben enlazarse directamente los archivos internos.
